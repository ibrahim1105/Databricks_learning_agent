# LakehousePrep AI — Databricks & SQL Learning Agent

This folder is ready to deploy on any free static web host:

1. **Netlify Drop (Fastest, 15 seconds)**: Drag and drop this folder or `lakehouseprep-deploy.zip` onto https://app.netlify.com/drop
2. **Cloudflare Pages**: Go to https://pages.cloudflare.com -> Create a project -> Direct Upload -> Upload `lakehouseprep-deploy.zip`
3. **GitHub Pages**: Push `index.html` to a GitHub repository -> Settings -> Pages -> Deploy from `main` branch
4. **Vercel**: Run `npx vercel` inside this folder or import via https://vercel.com/new
